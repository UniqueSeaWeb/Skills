Skill Atlas

このセッションで有効になっている Skills をカテゴリごとのパネルにまとめました。パネルを回して、スキルを選ぶと内容と呼び出し名が表示されます。

    ← → キー・スワイプ・ドラッグでも回せます

    パネルのスキルを選ぶと、ここに説明が表示されます。

    スキルのセットアップ方法

    使う場所によって追加方法が3通りあります。図はイメージで、実際のメニュー名は変わることがあります。

    Claude.ai・デスクトップアプリ

    設定画面でオンにする・ZIPをアップロードする

    1. 左下のメニューから 設定 を開き、機能（Capabilities） を選びます。
    2. コード実行とファイル作成 をオンにします。Skills はこの機能を使って動きます。
    3. Skills 欄で、使いたいスキルのスイッチをオンにします。
    4. 自作スキルは SKILL.md を含むフォルダを ZIP にして スキルをアップロード から追加します。

    Team・Enterprise プランでは、管理者が組織の設定で Skills を有効にしている必要があります。

    Claude Code・自作スキル

    決まったフォルダに SKILL.md を置く

    1. 自分だけで使うなら ~/.claude/skills/スキル名/、チームで共有するならリポジトリの .claude/skills/スキル名/ を作ります。
    2. その中に SKILL.md を作ります。補助のテンプレートやスクリプトも同じフォルダに置けます。
    3. プロジェクト用はコミットしてプッシュすれば、チームの全員が使えるようになります。

    SKILL.md の書き方

    name と description、その下に手順

    1. 先頭の --- で囲んだ部分に name と description を書きます。
    2. description には「何をするか」と「いつ使うか」を具体的に書きます。Claude はこれを見て、頼まれた内容に合うスキルを自動で読み込みます。
    3. 下の本文に、スキルが動くときの手順やルールを Markdown で書きます。

    Claude.ai にアップロードする場合、使える項目は name・description・license・compatibility・metadata・allowed-tools の6つです。

    Claude Code・配布されているスキル

    プラグインとしてインストールする

    1. マーケットプレイスを追加します: /plugin marketplace add anthropics/claude-plugins-official
    2. プラグインを入れます: /plugin install skill-creator@claude-plugins-official
    3. /skills で使えるスキルの一覧を確認します。
    4. /スキル名 で直接呼ぶか、内容に合う依頼をすると自動で使われます。プラグインのスキルは /プラグイン名:スキル名 の形になります。

    このページのスキル一覧にある design: や data: は、このプラグイン名です。

    スキル一覧の出典: このClaude Codeセッションに読み込まれているスキル（プラグイン: design / data / engineering / figma / cloudflare / frontend-design / modern-web-guidance / anthropic-skills、および組み込みスキル）。説明は要約です。
